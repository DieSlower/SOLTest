# Supercruise-style long travel

Offered during the architecture grill (SDD 1) as an alternative to the animated map jump and set aside: instead of the short warp, actually fly to a destination at very high speed with real travel time, as Elite Dangerous does.

- Needs a separate huge-speed flight regime layered on the flight-assist model.
- Would interact with origin rebasing (anchor switching mid-flight at extreme speeds) and with time-warp.
- Reaching Neptune would take real time, so it should be optional next to the jump map.
