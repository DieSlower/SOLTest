## Test contract (summary; full contract and case table in SDD section 4)

- `AutoRangeM(false)` = `AUTO_RANGE_M` = 1e7, `AutoRangeM(true)` = `AUTO_RANGE_TARGETED_M` = 1e3, `MANUAL_FLOOR_M`
  = 1e3, `MANUAL_FLOOR_M <= AutoRangeM(any)`.
- `StepManualRange(x, bZoomIn)`: invalid (not > 0, NaN) -> 1e3; +inf -> `MaxRangeM`; `x` within a relative 1e-9 of a
  power `p` counts as `p` and steps one decade (`p / 10` in, `p * 10` out); otherwise in = largest power of ten
  strictly below `x`, out = smallest strictly above; then clamp `[1e3, MaxRangeM]`. Results are exact constants.
- Ladders: from AUTO no target 1e7 -> 1e6 -> 1e5 -> 1e4 -> 1e3 -> 1e3; from AUTO with a target 1e3 in is a no-op, out
  1e4; from 1 AU in: 1e11, 1e10, ..., 1e3 (nine presses); from 1e3 out: 1e4, ..., 1e11, 1 AU.
- Old target-dependent floor cases and the "no snapping" cases are deleted, not disabled.
